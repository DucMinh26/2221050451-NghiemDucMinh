----------------------------------BUỔI HỌC SỐ 3--------------------------------------------------
-Tìm hiểu cấu trúc thư mục của dự án .Net MVC: - controller: xử lí, gọi, trả về - Model: chứa dữ liệu, logic, mapping data - View: hiển thị giao diện - wwwroot: chứa file tĩnh như css,js,image,... - Properties: Cấu hình môi trường chạy - appsettings.json: File cấu hình ứng dụng,Chuỗi kết nối CSDL,... - Program.cs: Điểm khởi động ứng dụng,Cấu hình Middleware, Khai báo MVC,... - File: Khai báo project .NET, framework, thư viện,...

- Tìm hiểu về định tuyến (Route) trong .Net MVC:

  - một URL → Controller → Action → (tham số)
- Tìm hiểu về Controller, View trong .Net MVC:

  - Controller giống như 1 người điều phối nhận y/c của người dùng rồi xử lí các y/c logic rồi quyết định trả về kết quả gì
  - View giống như một màn hình hiển thị chỉ hiển thị kết quả

----------------------------------BUỔI HỌC SỐ 4--------------------------------------------------

- ViewBag là:
  + Một đối tượng động (dynamic)
  + Dùng để chứa dữ liệu tạm thời
  + Chỉ tồn tại trong 1 request
  + chuyền 1 chiều controller -> View
